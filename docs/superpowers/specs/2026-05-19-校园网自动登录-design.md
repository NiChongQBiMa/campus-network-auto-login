# 校园网自动登录工具 - 设计文档

> 日期：2026-05-19 | 平台：Windows 7 | 语言：Python 3.8

## 一、项目概述

在 Windows 7 校园电脑上，开机后自动登录校园网认证系统（`http://10.26.13.2`），无需手动打开浏览器输入账号密码。

## 二、运行环境

- **操作系统**：Windows 7 及以上
- **Python 版本**：3.8（最后一个支持 Win7 的版本，仅打包时使用）
- **部署方式**：PyInstaller 打包为独立 `.exe`，目标电脑**无需安装 Python**
- **开机自启**：将 exe 快捷方式放入 `shell:startup` 启动文件夹

## 三、文件结构

```
校园网登录/
├── 校园网登录.exe      ← 主程序
├── config.ini           ← 配置文件
├── login.log            ← 运行日志（自动生成）
└── 使用说明.txt          ← 用户指南
```

## 四、配置文件设计

```ini
[account]
username = 2021001234
password = your_password
save_password = 1

[server]
login_url = http://10.26.13.2

[form]
# 以下字段首次运行时自动分析并写入，无需手动填写
action_url = http://10.26.13.2/login
username_field = username
password_field = password
save_field = remember
submit_field = login

[settings]
wait_network_timeout = 120
retry_interval = 5
```

- `[account]`：账号、密码、是否勾选"保存密码"
- `[server]`：校园网认证页面地址
- `[form]`：首次运行时自动分析填写，后续直接读取，加快登录速度
- `[settings]`：网络等待超时、重试间隔

## 五、核心流程

```
启动 exe
  │
  ├─ 读取 config.ini
  │
  ├─ 检测网络（3层递进）
  │   ├─ ① 本机IP检查（排除 169.254.x.x）
  │   ├─ ② TCP连接 10.26.13.2:80（3秒超时）
  │   └─ ③ HTTP GET 确认可达
  │   ├─ 不通 → 等待 retry_interval 秒 → 重试
  │   └─ 超时 → 弹窗"网络超时"，程序退出
  │
  ├─ 检查 [form] 段是否已配置
  │   ├─ 未配置：GET 页面 → 自动分析表单 → 写入 [form] → 继续
  │   └─ 已配置：直接读取字段映射
  │
  ├─ GET 登录页面（获取 CSRF token 等隐藏字段）
  │
  ├─ POST 账号密码 + 隐藏字段
  │
  └─ 检查返回结果
      ├─ 成功 → 弹窗"校园网已连接 ✅" + 写入日志
      └─ 失败 → 弹窗"登录失败 ❌" + 写入日志
```

## 六、弹窗设计

| 场景 | 内容 | 图标 | 自动关闭 |
|------|------|------|----------|
| 登录成功 | 校园网已连接 ✅ + 时间 | ℹ️ 信息 | 10秒 |
| 登录失败 | 登录失败 ❌，请检查账号密码 | ⚠️ 警告 | 不自动关闭 |
| 网络等待中 | 正在等待网络...（已等待N秒） | ⚠️ 警告 | 不自动关闭 |
| 网络超时 | 网络连接超时，校园网不可达 | ❌ 错误 | 不自动关闭 |

## 七、技术选型

| 依赖 | 用途 | 备注 |
|------|------|------|
| `requests` | HTTP 请求 | GET 页面、POST 登录 |
| `beautifulsoup4` | HTML 解析 | 首次分析表单结构 |
| `tkinter` | 弹窗 | Python 自带，无需安装 |
| `configparser` | 读取/写入 INI | Python 自带 |
| `socket` | TCP 连接检测 | Python 自带 |
| `logging` | 日志 | Python 自带 |

## 八、打包与部署

1. 开发机安装 Python 3.8 + PyInstaller
2. `pip install requests beautifulsoup4 pyinstaller`
3. `pyinstaller --onefile --noconsole --name 校园网登录 main.py`
4. 将 `dist/校园网登录.exe` 和 `config.ini` 拷贝到目标电脑
5. 在目标电脑按 `Win+R` 输入 `shell:startup`，放入 exe 快捷方式
